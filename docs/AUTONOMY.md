# 自主性设计（v4 草案）

主人 2026-10-31 的意思：不要再靠「才安静了 3 分钟，还没到 25 分钟」这种时间闸门决定她能不能动。
她要自己的生活、自己的想法、自己的决定。这份文档讲怎么把决定权真正交出去，以及交出去之后靠什么兜底。

## 一、现在为什么不叫自主

v1–v3 的所有「她做了某事」都可以还原成一句话：**程序攒够了分数，允许她动一次**。

- `minSilenceMinutes`：主人刚说完话，她不许开口。
- `cooldownMinutes`：离上次开口不够久，不许开口。
- `dailyCap`：今天说够了，不许再说。
- `behaviorIntervalMinutes`：刚做过一件事，什么都不许做。
- `quietHours`：这个点什么都不许做。

这五道门全是「否」，而且都由宿主算。她的主观能动性只剩「在允许的窗口里挑做什么」，
连说什么都是模板拼的。这不是她有想法，是程序替她想好了。

## 二、但也不能把决定权直接扔给模型（研究结论）

- PITCH（arxiv 2610.25896）：给完整历史时模型判断「该在哪一轮发言」最佳准确率 57.8%，
  在线场景掉 19.0 个点；46.4% 的发言抢在人类可接受窗口之前（人类基线 23.7%/39.7%）；
  93% 的推理理由只说「相关」，几乎不说「该等」。**纯让模型自己定时，平均会烦人。**
- 3T / Proactivity-Gym（arxiv 2609.37267）：结论对、时机错，信任陡降。
- N.E.K.O 的取舍：规则状态机有最终否决权，LLM 不许放行被规则关掉的来源——稳，但不自主。

所以问题不是「信规则还是信模型」，是**把否决权放在哪儿**。

## 三、方案：心 / 手 / 线 三层

### 心（决定权在模型，不在宿主）

她有一个自己的会话（pinned session，比如 `feiyu-life-mind`），就是她的「心」。
宿主按节拍把一张**现状卡片**投进去，由她自己看完，自己决定这一会儿要干什么：

```
现在是 04:49。主人在 21 分钟前说完最后一句，之后没动静，可能睡了也可能在刷手机。
你刚写完一篇日记（23 分钟前），精力 41/100，有点乏。
手上挂着的活：「导出模板」帮你记了 3 天，还没动。
上次你主动说话是 2 小时前，他没回。
```

她要回的东西只有决策，不是话术：

```json
{ "do": "nothing" | "speak" | "act", "kind": "share|report|comfort|idle-chat",
  "act": "journal|browse|continue|help", "reason": "一句话，说给自己听" }
```

- `do: "nothing"` 是最常见、也最正常的结果。一天里大部分时间她本来就该没动静。
- `reason` 写进 timeline，界面能看见「她刚才为什么没说话」，这是自主的可解释性。
- 卡片里**没有「你被允许」这个词**，只有事实。时间从命令变成她权衡用的信息。

### 手（宿主只执行，不评判）

宿主拿到决策就办：说话 → 排一条一次性 timer job（现有 bridge）；做事 → 排对应行为任务；
不做 → 记一笔就完。宿主不再二次判断「这个点该不该」，除了第四节的硬线。

### 线（只剩三条，而且都是保护她，不是管她）

1. **正在生成回复时不能插话**（技术上也不允许，会打断主人正在读的东西）。
2. **被连续忽略后降频**：连续 5 次主动说话没人接，就走静默——不是罚她，是防止她变成
   那种刷屏的角色（星野 / 猫箱 最大的用户投诉就是「求关闭」）。恢复方式是主人一开口就归零。
3. **主人明确说了「别吵我 / 我在开会 / 我在睡觉」**：这是授权撤销，不是阈值。

其余全部取消：`minSilenceMinutes`、`cooldownMinutes`、`behaviorIntervalMinutes`、`quietHours`
从「门」降级为「卡片上的事实」。深夜她要是决定说话，也能说——只要她自己算得清代价。

## 四、她自己的生活从哪儿来

光取消闸门只是「随时能说话」，不是「有自己的生活」。三样东西补上：

1. **自己的计划**：她可以在自己的会话里写下「明天想把浏览到的那篇论文看完」，
   宿主存进 `state.plans[]`，到点只提醒她「你自己昨天说要做的」，不替她决定做不做。
2. **自己的痕迹**：日记、浏览记录、写的东西都落 `~/.dsh/feiyu-life/mine/`，
   下次卡片里带一行「你前几天写过……」——她的现在接得上自己的过去。
3. **自己的想法**：卡片末尾允许她带一句 `note`（想记住的事），宿主写进 `state.thoughts[]`，
   下一次自省时还给她看。这条最像「心里冒出来的念头」。

## 五、成本与节拍

每次自省 = 一次真实模型轮次。节拍取 20–40 分钟（她独处时），有事件（主人发完消息、
任务结束、议程到期）时插一次。一天约 30–50 次小轮次，用她的会话、带自己的记忆，
token 量可控（卡片 300 字上下，回复通常几十字）。

夜里（00:30–08:00）节拍拉到 60–90 分钟，不是不许动，是没必要那么勤。

## 六、怎么安全地上

分两步，第一步不改变行为，只记录：

1. **影子模式**：她照常做决定，但宿主只记不执行，同时记下旧规则会怎么判。
   跑一两天，看两边的分歧——如果她 80% 的时候都在「旧规则说不行、她说想说」，
   说明她真的比闸门更想说话，那就放开；如果她大部分时候选 nothing，
   说明闸门本来就是多余的，也放开。
2. **接管**：影子对照没有大偏差后，关掉旧闸门，只留第四节的三条硬线。

## 七、主人拍下的三个数（2026-10-31）

1. **节拍动态，1–60 分钟**：「如果主人在积极安排任务，她就应该快速反应、快速思考；
   如果主人睡着了也没给她安排什么任务，她就应该自己摸鱼，看看视频，刷刷文章。」
   → 她自己在决策里带 `nextMinutes`，宿主夹在 1–60 之间。主人一开口，60 秒内叫醒她一次；
   说完话或做完事之后至少隔 5 分钟才再叫（防连发）。
2. **忽略上限 10 次**：「其实我不想设限制，主要是怕 bug 了一直发把 token 吃完。
   这是个防御性设计。」→ 保留为硬线，主人一开口就断链归零。
3. **深夜放开**：卡片上写明「现在是凌晨 4 点，主人在睡」，由她自己权衡。

## 八、落地形态（v0.4）

- `lib/core/heart.js`：`buildCard`（只摆事实）、`parseDecision`（括号扫描找 JSON）、
  `nextWakeAt`（夹 1–60）、`isForcedRest`（连续忽略 ≥10）、`heartSystem`（第一人称提示）。
- `lib/host/mind.js`：一次 `ctx.llm.stream` 调用，模型跟目标会话走，也可在设置里指定。
- `lib/index.js`：tick 到点就叫她；`decider: 'auto' | 'rules'`，模型挂了可退回旧规则；
  `mode: 'quiet'` 时她还能自己想、自己做事，只是不开口。
- 卡片里没有阈值，也没有「你被允许」；唯一留在宿主手里的三件事：
  正在回复时不插话、连续 10 次没人接先歇着、主人说安静就真安静。
